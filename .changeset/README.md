# Changesets

Each Markdown file here describes a change that should be released: which packages it affects,
the bump type and a summary for the changelog. Add one with `pnpm changeset`.

`@moveable-next/react`, `@moveable-next/croact`, `@moveable-next/vanilla` and `@moveable-next/vue3`
always share one version (`fixed` in `config.json`); `@moveable-next/helper` is versioned on its own.
See [CONTRIBUTING.md](../CONTRIBUTING.md) for how versions are released.
